# GitHub Copilot PR Review Test

This project is created to **test GitHub Copilot's Pull Request review feature**.  
It includes intentionally bad code in the `Loader` component to evaluate how well Copilot identifies and suggests improvements.

## 🔍 Purpose

- Check how **GitHub Copilot** reviews PRs.
- Test suggestions on:
  - Unused variables
  - Accessibility issues
  - Poor coding practices
  - Bad React patterns
